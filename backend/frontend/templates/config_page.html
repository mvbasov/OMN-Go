General

Network & Access

A box that stays empty keeps the password that this device already holds. Type in a box to change that password. Empty a revealed box to remove that password.
When off, the server answers only this device (127.0.0.1 / localhost). When on, it listens on all network interfaces, and other devices can connect. Each write from another device needs the admin password. The change applies after a restart of the application.

Identifies this device in database backup filenames (e.g. pixel7, desktop). Letters, digits, '_' and '-' only; anything else is replaced. Clearing the field resets it to the OS hostname.
How many backups to keep per database on the Database Backups page; creating a new backup deletes the oldest beyond this count. Default 3.
Limits how large an image or JSON file can be when uploaded from the editor (drag-and-drop) or shared into Quick Notes from Android. Default 3 MB.

Android Integration

Which system bars the Android app hides. Immersive also hides the navigation bar; swipe from the edge to bring the bars back temporarily. Applies as soon as you save - no restart needed. Android only; ignored on desktop and in LAN browsers.
Lets a note launch Android "intent:" URIs when tapped in the app - e.g. opening a Settings screen with [Wi-Fi](intent:#Intent;action=android.settings.WIRELESS_SETTINGS;end;). Off by default. Android only; ignored on desktop and in LAN browsers.
Additionally allows notes to run shell commands via Termux (RUN_COMMAND). Requires "Enable intent: links" above to also be on, Termux installed with allow-external-apps=true, and its RUN_COMMAND permission granted; each command asks for confirmation before it runs. Security: notes arriving via git sync or LAN editing could contain commands - leave this off unless you author your own notes.

Search

Searching the page you have open always works and needs nothing - no index, no settings, no memory. Everything below is about searching all your notes at once, which does need an index.
Builds an index of the content selected below and keeps it in memory - roughly half the size of the text it covers (about 3 MB for 2000 notes, 13 MB for 10000). Leave this off on a device short of memory; page search keeps working either way.
Every kind you add is more memory held for as long as the app runs. Unticking all of them means the index covers nothing.
katex.min.js, omn-go-core.js and the rest of the app's own code. They are several times the size of a typical note collection and rarely what you are looking for - but useful if you want to grep the app itself.
Where a search starts. The search box can switch for a single query without changing this.

Logging

The app writes a message for each thing it does. A message has a subsystem in brackets and a level in parentheses, for example [sync] (debug) Staging file: Todo.md. Open the browser console to read them.
Both are off until you ask for them. Errors have no switch and always appear.
%%LOG_TAG_BOXES%% A debug or info message appears when its level is on and its subsystem is ticked here. An error appears whatever you tick.
